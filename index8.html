JavaScript Events

Learn Common Events

What is an Event?

An event is an action that happens on a webpage.

Example: Click, Double Click, Mouse Over and Value Change.

1. onclick

When an element is clicked.

2. ondblclick

When an element is double clicked.

3. onmouseover

When mouse moves over an element.

4. onchange

When value changes.

5. Form Event

Quick Summary

onclick → Click

ondblclick → Double Click

onmouseover → Mouse Over

onchange → Value Change

onload → Page Load

onsubmit → Form Submit
