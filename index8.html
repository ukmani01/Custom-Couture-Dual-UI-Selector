JavaScript Events

Learn Common Events with Simple Examples

Action → Event → Function → Output

What is an Event?

An Event is an action or happening on a webpage.

When the user performs an action, JavaScript can run a function.

Example:

User clicks a button → onclick event happens → function runs → output is displayed.

How Event Works?

User Action
     ↓
Event
     ↓
Function
     ↓
Output

Example: Click Button → onclick → showMessage() → Hello

1. onclick

Meaning: onclick is used when an element is clicked.

Syntax

<button onclick="functionName()"> Click </button>

Example Code

<button onclick="showMessage()">Click Me</button>
<p id="output"></p>
<script>
function showMessage() {
    document.getElementById("output").textContent = "Button Clicked!";
}
</script>

Try It

Remember: Button click → onclick → function → output

2. ondblclick

Meaning: ondblclick is used when an element is double clicked.

Example Code

<button ondblclick="showMessage()">Double Click</button>
<script>function showMessage() { document.getElementById("output").textContent = "Double Clicked!"; }</script>

Try It

Remember: Two clicks → ondblclick → function

3. onmouseover

Meaning: onmouseover works when the mouse moves over an element.

Example Code

<button onmouseover="showMessage()">Move Mouse Here</button>

Try It

Remember: Mouse over → onmouseover → function

4. onchange

Meaning: onchange works when an input or select value changes.

Example Code

<select onchange="showCourse()">
    <option>HTML</option>
    <option>CSS</option>
</select>
<script>
function showCourse() {
    let course = document.getElementById("course").value;
    document.getElementById("output").textContent = course;
}
</script>

Try It

Remember: Value change → onchange → function

5. onload

Meaning: onload works when the webpage finishes loading.

Example

<body onload="pageLoaded()">
<script>function pageLoaded() { alert("Page Loaded!"); }</script>

When the page is completely loaded, the function will run.

6. onsubmit

Meaning: onsubmit works when a form is submitted.

Basic Example

<form onsubmit="showName(event)">
    <input type="text" id="name">
    <button type="submit">Submit</button>
    <p id="output"></p>
</form>
<script>
function showName(event) {
    event.preventDefault();
    let name = document.getElementById("name").value;
    document.getElementById("output").textContent = "Hello " + name;
}
</script>

Try It


7. Check Empty Input

If the input is empty, we can use an if condition.

Empty input → Border becomes red → "Please enter" message appears.

Example Code

let input = document.getElementById("name");
if (input.value == "") {
    input.style.border = "2px solid red";
    output.textContent = "Please enter your name";
}

🧠 DSA & JavaScript — Complete Learning Guide

🎯 Goal: This guide is for absolute beginners. It explains what DSA and LeetCode are, and gives a clear, step-by-step learning path — from your very first line of JavaScript to building real projects.

🧠 What is DSA?

DSA = Data Structures + Algorithms

It is about how to store data efficiently and how to solve problems using minimal time and memory.

Example: You have an array [10, 20, 30, 40, 50]. You want to find if 40 exists.
  • Linear Search: Check each element one by one → 10 ❌ 20 ❌ 30 ❌ 40 ✅
  • This is a DSA concept — how you search matters!

💻 What is LeetCode?

LeetCode is a platform where you get programming problems. You can solve them using JavaScript, Python, Java, C++, etc.

Example Problem:
Given an array of numbers, find two numbers whose sum equals a target.
const nums = [2, 7, 11, 15]; const target = 9;
Answer: 2 + 7 = 9

This uses DSA concepts like Arrays, Hashing, Time Complexity.

🔥 DSA vs LeetCode

📘 DSA

  • A concept / subject
  • Data Structures
  • Algorithms
  • Big O
  • Arrays, Stacks, Trees, Graphs

💻 LeetCode

  • Practice platform
  • Problems
  • Coding challenges
  • Test cases
  • Array problems, Stack problems, etc.
🎯 Simple way to understand:
Learn DSA → Understand how HashMap works.
Practice on LeetCode → Solve a problem using HashMap.

Order: Learn DSA → Understand concept → Solve LeetCode problems → Improve problem-solving.

  4. Strings — Reverse, Palindrome, Character frequency, Anagram, String searching
  5. Objects / Hashing ⭐ — Object as Hash Map, Map, Set, Frequency counter, Fast lookup
  6. Recursion — Base case, Recursive case, Call stack, Factorial, Fibonacci
  7. Searching — Linear Search, Binary Search
  8. Sorting — Bubble, Selection, Insertion, Merge, Quick, JavaScript .sort()
  9. Stack — LIFO, Push/Pop, Parentheses matching, Undo/Redo
  10. Queue — FIFO, Enqueue/Dequeue
  11. Linked List — Node, Head, Traversal, Insert, Delete
  12. Trees — Binary Tree, BST, Traversals (Inorder, Preorder, Postorder)

🎯 How Much DSA Do You Need?

If your goal is JavaScript → React → Node.js → MERN → Real-time projects, then you need:

  • Programming Logic
  • Big O
  • Arrays, Strings, Objects/Map/Set
  • Recursion, Searching, Sorting
  • Stack, Queue
  • Linked List, Trees, Graph basics
  • Problem-solving patterns (Two Pointers, Sliding Window, etc.)

You do NOT need advanced DP, segment trees, tries, or complex graph algorithms at the start.

💡 Why DSA Matters — A Real Example

Problem: Does an array contain duplicate values?

Basic solution (O(n²)): for (let i = 0; i < arr.length; i++) { for (let j = i + 1; j < arr.length; j++) { if (arr[i] === arr[j]) return true; } }

Better solution using Set (O(n)): const seen = new Set(); for (const value of arr) { if (seen.has(value)) return true; seen.add(value); }

This is DSA in action — using the right data structure makes your code faster and cleaner.

⭐ Most Important Thing

Don't start DSA before you understand JavaScript basics.

First, learn to think in JavaScript — how to solve a problem using variables, loops, functions, arrays, and objects.

Then, learn DSA to make those solutions faster and more efficient.

Then, practice on LeetCode to build confidence.

This sequence is smooth, beginner-friendly, and prepares you for real-world projects and interviews.

function linearSearch(numbers, target) {
    for (let i = 0; i < numbers.length; i++) {
        if (numbers[i] === target) {
            return i;
        }
    }
    return -1;
}

What is Node.js?

Node.js is a JavaScript runtime. It allows us to run JavaScript outside the browser.

Normally JavaScript runs inside Chrome. Node.js lets us run JavaScript directly on our computer/server.

Browser → JavaScript → UI
Node.js → JavaScript → Backend / Server / Tools
STEP 01

Open Official Site

Go to nodejs.org and open the Download section.

Download
STEP 02

Choose LTS

For beginners, choose the LTS release — stable and well-supported.

STEP 03

Windows Installer

Download the Windows installer (.msi) that matches your system.

STEP 04

Install

Open installer → Next → Accept → Next → Install. Default options are fine.

Check Installation

Open Command Prompt or PowerShell. Then run:

node -v
npm -v

If both commands show a version number, Node.js and npm are installed correctly.

What is npm?

npm = Node Package Manager. It helps us install and manage JavaScript packages.

Example: Express, Mongoose and many other backend libraries can be installed using npm.
