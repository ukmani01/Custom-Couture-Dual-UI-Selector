Tools

Server vs Compass — What does each do?

இந்த five tools சேர்ந்து work செய்கின்றன. Each has a distinct role.

ToolPurpose
MongoDB Community ServerActual database server. Node.js இதனுடன் connect ஆகும்.
MongoDB CompassGUI மூலம் MongoDB-ஐ பார்க்கவும் documents insert/manage செய்யவும் பயன்படும்.
mongoshMongoDB command-line shell — server-ஐ directly query செய்யும்.

Important: Compass மட்டும் install செய்தால் Node.js local database connection உருவாகாது. MongoDB Server running-ஆ இருக்க வேண்டும்.

Create app.js — Read existing data

Paste this complete code into app.js:

app.js
import mongoose from "mongoose"
import http from "http"

// Connect MongoDB
mongoose.connect("mongodb://127.0.0.1:27017/ccc")
  .then(() => {
    console.log("MongoDB Connected!")
  })
  .catch((error) => {
    console.log("Connection Error:", error)
  })

// Schema
const studentSchema = new mongoose.Schema(
  {
    name:       String,
    age:        Number,
    department: String,
    year:       Number,
    email:      String,
    marks:      Number
  },
  { collection: "student" }
)

// Model
const Student = mongoose.model("Student", studentSchema)

// HTTP Server
const server = http.createServer(async (req, res) => {

  try {
    const students = await Student.find()

    let html = `
      <html>
      <head><title>Student Data</title></head>
      <body>
        <h1>Student Details</h1>
    `

    students.forEach(stu => {
      html += `
        <h2>${stu.name}</h2>
        <p>Age: ${stu.age}</p>
        <p>Department: ${stu.department}</p>
        <p>Year: ${stu.year}</p>
        <p>Email: ${stu.email}</p>
        <p>Marks: ${stu.marks}</p>
        <hr>
      `
    })

    html += `</body></html>`

    res.writeHead(200, { "Content-Type": "text/html" })
    res.end(html)

  } catch (error) {
    console.log(error)
    res.writeHead(500, { "Content-Type": "text/plain" })
    res.end("Database Error")
  }

})

server.listen(3000, () => {
  console.log("Port running on 3000")
})
Extended Version

Create new data via POST

இந்த version-ல் /add POST route மூலம் new student data create செய்யலாம்.

app.js — with POST /add route
import mongoose from "mongoose"
import http from "http"

mongoose.connect("mongodb://127.0.0.1:27017/ccc")
  .then(() => { console.log("MongoDB Connected!") })
  .catch((error) => { console.log("Connection Error:", error) })

const studentSchema = new mongoose.Schema(
  { name: String, age: Number, department: String, year: Number, email: String, marks: Number },
  { collection: "student" }
)

const Student = mongoose.model("Student", studentSchema)

const server = http.createServer(async (req, res) => {

  if (req.url == "/add" && req.method == "POST") {

    console.log("request received for create")

    await Student.create({
      name:       "maariyappan",
      age:        56,
      department: "cse",
      year:       2008,
      email:      "mm@gmail.com",
      marks:      123
    })

    res.writeHead(200, { "Content-Type": "text/plain" })
    res.end("successfully added")

  } else if (req.url == "/" && req.method == "GET") {

    const students = await Student.find()

    let html = `<html><head><title>Student Data</title></head><body><h1>Student Details</h1>`

    students.forEach(stu => {
      html += `
        <h1>${stu.name}</h1>
        <p>Age: ${stu.age}</p>
        <p>Department: ${stu.department}</p>
        <p>Year: ${stu.year}</p>
        <p>Email: ${stu.email}</p>
        <p>Marks: ${stu.marks}</p>
        <hr>
      `
    })

    html += `</body></html>`

    res.writeHead(200, { "Content-Type": "text/html" })
    res.end(html)
  }

})

server.listen(3000, () => {
  console.log("Port running on 3000")
})

Understand the Code

What each part does

①

Import

import mongoose from "mongoose"
import http from "http"

mongoose → MongoDB operations. http → Node.js HTTP server.

②

Connection

mongoose.connect(
  "mongodb://127.0.0.1:27017/ccc"
)

127.0.0.1 = this computer. 27017 = MongoDB port. ccc = database name.

③

Schema

Schema describes the student document structure — name, age, department, year, email, marks. { collection: "student" } maps it to the exact collection name in MongoDB.

④

Model

const Student =
  mongoose.model("Student", schema)

Model is used to perform operations like find(), create().

⑤

Read data

const students =
  await Student.find()

Reads all existing documents from the student collection.

⑥

HTML Response

res.writeHead(200, {
  "Content-Type": "text/html"
})
res.end(html)

200 = success. res.end() sends the response.

Troubleshooting

Common errors & fixes

Error: Client must be connected before running operations

Usually the MongoDB connection was closed or the query ran before the connection was ready.

FIX

For this lab, do not call mongoose.connection.close().

Error: ECONNREFUSED 127.0.0.1:27017

MongoDB Server is probably not running.

FIX
net start MongoDB

Error: Cannot use import statement outside a module

The project is not configured for ES modules.

FIX — add to package.json
"type": "module"

Error: Cannot find package 'mongoose'

Mongoose is not installed in the project folder.

FIX
npm install mongoose

Error: Cannot find collection / data is empty

Check Compass carefully. Database and collection names must match exactly.

VERIFY
Database:   ccc
Collection: student
