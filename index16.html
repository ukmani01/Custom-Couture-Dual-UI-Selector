9. Create app.js

இந்த complete code-ஐ app.js file-ல் paste செய்யவும்.

import mongoose from "mongoose"
import http from "http"

// Connect MongoDB
mongoose.connect("mongodb://127.0.0.1:27017/ccc")
  .then(() => {
    console.log("MongoDB Connected!");
  })
  .catch((error) => {
    console.log("Connection Error:", error);
  })

// Schema
const studentSchema = new mongoose.Schema(
  {
    name: String,
    age: Number,
    department: String,
    year: Number,
    email: String,
    marks: Number
  },
  {
    collection: "student"
  }
)

// Model
const Student = mongoose.model("Student", studentSchema)


// Server
const server = http.createServer(async (req, res) => {

  try {
    const students = await Student.find()

    let html = `
      <html>
      <head>
        <title>Student Data</title>
      </head>
      <body>
        <h1>Student Details</h1>
    `

    students.forEach(stu => {
      html += `
        <h2>${stu.name}</h2>
        <p>Age: ${stu.age}</p>
        <p>Department: ${stu.department}</p>
        <p>Year: ${stu.year}</p>
        <p>Email: ${stu.email}</p>
        <p>Marks: ${stu.marks}</p>
        <hr>
      `
    })

    html += `
      </body>
      </html>
    `

    res.writeHead(200, { "Content-Type": "text/html" })
    res.end(html)

  } catch (error) {

    console.log(error)

    res.writeHead(500, { "Content-Type": "text/plain" })
    res.end("Database Error")

  }

})

server.listen(3000, () => {
  console.log("Port running on 3000")
})

11. Understand the Code

1. Import

import mongoose from "mongoose"
import http from "http"

mongoose → MongoDB connection and database operations.
http → Basic Node.js HTTP server.

2. MongoDB Connection

mongoose.connect("mongodb://127.0.0.1:27017/ccc")

127.0.0.1 → this computer.
27017 → MongoDB port.
ccc → database name.

3. Schema

const studentSchema = new mongoose.Schema({
  name: String,
  age: Number,
  department: String,
  year: Number,
  email: String,
  marks: Number
}, {
  collection: "student"
})

Schema describes the student document structure.

4. Model

const Student = mongoose.model("Student", studentSchema)

Model is used to perform MongoDB operations such as find().

5. Request and Response

http.createServer(async (req, res) => {
  ...
})

Browser sends a request → Node.js receives it → Node.js reads MongoDB → Node.js sends HTML response.

6. Read Data

const students = await Student.find()

This reads existing documents from the student collection.

7. HTML Response

res.writeHead(200, { "Content-Type": "text/html" })
res.end(html)

200 means successful HTTP response. text/html tells Chrome that the response contains HTML. res.end() sends the response and finishes it.

13. Common Errors

Error: Client must be connected before running operations

Usually the MongoDB connection was closed or the query ran before the connection was ready.

For this lab, do not call:

mongoose.connection.close()

Error: ECONNREFUSED 127.0.0.1:27017

MongoDB Server is probably not running.

net start MongoDB

Error: Cannot use import statement outside a module

Make sure package.json contains:

"type": "module"

Error: Cannot find package 'mongoose'

npm install mongoose

Error: Cannot find collection/data

Check Compass carefully:

Database: ccc
Collection: student

15. One-Minute Teaching Explanation

Teacher: "First, MongoDB Server stores our data. Compass is only the GUI through which we can see and insert that data. We create a database called ccc and a collection called student. Then Node.js connects to the local MongoDB server using Mongoose. When we open localhost:3000, Chrome sends a request to our Node.js HTTP server. The server uses Student.find() to get the existing data. Then we create HTML and send it back using res.writeHead(200) and res.end(). Chrome displays that HTML."
