9. Create app.js

இந்த complete code-ஐ app.js file-ல் paste செய்யவும்.

import mongoose from "mongoose"
import http from "http"

// Connect MongoDB
mongoose.connect("mongodb://127.0.0.1:27017/ccc")
  .then(() => {
    console.log("MongoDB Connected!");
  })
  .catch((error) => {
    console.log("Connection Error:", error);
  })

// Schema
const studentSchema = new mongoose.Schema(
  {
    name: String,
    age: Number,
    department: String,
    year: Number,
    email: String,
    marks: Number
  },
  {
    collection: "student"
  }
)

// Model
const Student = mongoose.model("Student", studentSchema)


// Server
const server = http.createServer(async (req, res) => {

  try {
    const students = await Student.find()

    let html = `
      <html>
      <head>
        <title>Student Data</title>
      </head>
      <body>
        <h1>Student Details</h1>
    `

    students.forEach(stu => {
      html += `
        <h2>${stu.name}</h2>
        <p>Age: ${stu.age}</p>
        <p>Department: ${stu.department}</p>
        <p>Year: ${stu.year}</p>
        <p>Email: ${stu.email}</p>
        <p>Marks: ${stu.marks}</p>
        <hr>
      `
    })

    html += `
      </body>
      </html>
    `

    res.writeHead(200, { "Content-Type": "text/html" })
    res.end(html)

  } catch (error) {

    console.log(error)

    res.writeHead(500, { "Content-Type": "text/plain" })
    res.end("Database Error")

  }

})

server.listen(3000, () => {
  console.log("Port running on 3000")
})

const Student = mongoose.model("Student", studentSchema)

Model is used to perform MongoDB operations such as find().

http.createServer(async (req, res) => {
  ...
})

Browser sends a request → Node.js receives it → Node.js reads MongoDB → Node.js sends HTML response.

const students = await Student.find()

This reads existing documents from the student collection.

res.writeHead(200, { "Content-Type": "text/html" })
res.end(html)

200 means successful HTTP response. text/html tells Chrome that the response contains HTML. res.end() sends the response and finishes it.

MongoDB Complete Beginner Guide

MongoDB is a database system. We use MongoDB to store application data. In this guide, we will learn how to install MongoDB Community Server, check the version, use MongoDB Shell, insert data, view data in Compass, and finally connect MongoDB with Node.js using Mongoose.

1. Our Main Goal

Windows Computer ↓ MongoDB Community Server ↓ MongoDB Server (mongod) ↓ MongoDB Shell (mongosh) / MongoDB Compass ↓ Database + Collections + Documents ↓ Node.js + Express + Mongoose ↓ Our Website

2. What Do We Need?

  • Windows 10/11 computer
  • MongoDB Community Server – Database server
  • MongoDB Compass – GUI tool
  • MongoDB Shell (mongosh) – Command-line tool
  • Node.js – Backend JavaScript runtime
  • Mongoose – Connect Node.js with MongoDB
  • VS Code – Code editor

3. MongoDB Community Server

MongoDB Community Server is the main database server. It stores our data and handles database requests.

During installation, MongoDB files are automatically installed inside the Program Files folder. 

C:\Program Files\MongoDB\Server\8.0\bin

We do not need to manually copy and paste MongoDB files. The installer does this automatically.

4. What is Environment Variable?

Environment Variable PATH tells Windows where the MongoDB program files are located.

Example:

C:\Program Files\MongoDB\Server\8.0\bin

If this path is added to PATH, we can run MongoDB commands directly from CMD. 

mongod --version

We do not use Environment Variables to install MongoDB. MongoDB is already installed. PATH simply helps Windows find the MongoDB commands.

Important

MongoDB installation and Environment Variable PATH are two different things.

  • MongoDB Installation → Installs MongoDB files.
  • PATH → Helps CMD find MongoDB commands.

5. Check MongoDB Server Version

Step 1

Open CMD.

Run:

mongod --version

Example output:

db version v8.0.13

This means MongoDB Server version 8.0.13 is installed.

6. What is mongod?

mongod means MongoDB Server process.

It is responsible for running the MongoDB database server. 

mongod

However, if MongoDB was installed as a Windows Service and the service is already running, we do not need to manually start mongod every time.

7. Check MongoDB Windows Service

Run this command in CMD:

net start MongoDB

If the service is already running, Windows may show that the MongoDB service is already running.

If it is not running, this command can start the MongoDB service when MongoDB was installed as a Windows service.

8. What is mongosh?

mongosh means MongoDB Shell.

It is a command-line tool used to connect to a running MongoDB Server and execute MongoDB commands. 

mongosh

Important: mongosh is not the MongoDB Server.

Remember This

Tool Purpose
mongod Runs the MongoDB Server
mongosh Command-line tool to interact with MongoDB
MongoDB Compass GUI tool to view and manage MongoDB

9. Open MongoDB Shell

Step

Open CMD and run:

If it connects successfully, you can start using MongoDB commands.

10. Select a Database

Run:

This selects the college database.

MongoDB creates the database when we store the first document.

11. Create a Collection

Example:

db.createCollection("students")

This creates a collection called students.

12. CRUD Operations

CRUD means four basic database operations:

Operation Meaning MongoDB Command
Create Add data insertOne()
Read Get data find()
Update Change data updateOne()
Delete Remove data deleteOne()

13. CREATE – Insert Data

Insert one student:

db.students.insertOne({
  name: "Mani",
  age: 25,
  course: "MERN"
})

This stores one document inside the students collection.

14. READ – View Data

View all students:

db.students.find()

Find a specific student:

db.students.find({
  name: "Mani"
})

15. UPDATE – Change Data

db.students.updateOne(
  { name: "Mani" },
  { $set: { age: 26 } }
)

This changes Mani's age from 25 to 26.

16. DELETE – Remove Data

db.students.deleteOne({
  name: "Mani"
})

This removes the matching document.

17. Useful MongoDB Commands

Show all databases:

show dbs

Show current database:

db

Show collections:

show collections

Count documents:

db.students.countDocuments()

Node.js can connect directly to MongoDB using Mongoose.

mongosh is mainly useful when we want to manually work with MongoDB through the command line.

MongoDB Shell (mongosh) – Complete CMD Guide

What are we learning?

MongoDB Shell is called mongosh. It allows us to communicate with MongoDB from the command line.

We will install mongosh, configure PATH, check the installation, connect to MongoDB, and practice basic database commands.

1. What is mongosh?

mongosh means MongoDB Shell.

It is a command-line interface for MongoDB. We can use it to run MongoDB commands from CMD or Terminal.

For example:

mongosh

After opening mongosh, we can execute commands such as: 

show dbs
use college
show collections

2. Is mongosh the MongoDB Server?

No.

mongosh is NOT the MongoDB Server.

Component Purpose
MongoDB Server Runs and stores the database
mongosh Command-line tool to communicate with the server

3. Download MongoDB Shell

Step 1

Download MongoDB Shell for Windows from the official MongoDB website.

Choose the Windows version suitable for your computer.

For most modern Windows computers, choose the Windows x64 version.

4. Install MongoDB Shell

Step 2

Open the downloaded installer.

Follow the installation steps and complete the installation.

The installer will place the mongosh.exe file in its installation folder.

5. Find mongosh.exe

After installation, find the folder that contains: 

mongosh.exe

The exact installation location can be different depending on the version and installation method.

The important thing is: Find the folder containing mongosh.exe.

6. Add mongosh to Environment Variable PATH

Step 3

We add the folder containing mongosh.exe to the Windows PATH.

Open Windows Search and type:

Environment Variables

Then open:

Edit the system environment variables

Click:

Environment Variables
        ↓
Path
        ↓
Edit
        ↓
New

Paste the folder path that contains mongosh.exe.

Why do we add PATH?

PATH tells Windows where to find mongosh.exe.

After PATH is configured, we can simply type: 

mongosh

from any CMD location.

7. Restart CMD

Step 4

Close all existing CMD windows.

Open a new CMD window.

This is important because the new PATH value may not be available in an already-open CMD window.

8. Check mongosh Version

Step 5

Run:

mongosh --version

Example:

2.x.x

If a version number appears, mongosh is correctly installed and available from CMD.

9. If "mongosh is not recognized" Appears

If you see: 

'mongosh' is not recognized as an internal or external command

It usually means Windows cannot find mongosh.exe.

Check these:

  1. Is MongoDB Shell actually installed?
  2. Does mongosh.exe exist?
  3. Did you add the correct folder to PATH?
  4. Did you open a new CMD after changing PATH?

10. Find mongosh Using CMD

Step 6

Run:

where mongosh

If PATH is correctly configured, CMD can show the location of mongosh.exe.

11. Start MongoDB Shell

Step 7

Run:

mongosh

mongosh will try to connect to the local MongoDB Server.

If the server is running, you can start executing MongoDB commands.

12. Check Connection

After running: 

mongosh

You may see a prompt such as: 

test>

This means you are inside the MongoDB Shell.

13. Connect to a Specific MongoDB Server

You can also provide a MongoDB connection string: 

mongosh "mongodb://127.0.0.1:27017"

This tells mongosh to connect to the MongoDB server running on the local computer.

14. Show Databases

Step 8 
show dbs

This displays the databases available on the server.

15. Select a Database

use college

Now the current database is college.

16. Show Current Database

db

This shows the current database.

db.createCollection("students")

This creates a collection called students.
